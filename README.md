# Neural Speech Enhancement Research Pipeline

## Overview

This repository contains a modular speech enhancement pipeline developed as part of an internship project.

Current functionality includes:

- TIMIT dataset preprocessing
- Noise generation
- Feature extraction
- PyTorch dataloaders
- CNN baseline
- Enhancement inference pipeline

Future work includes:

- DeepFilterNet
- FullSubNet
- SpeechBrain enhancement
- Objective evaluation (PESQ, STOI, SI-SDR)
